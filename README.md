# GlowNest Website

This is the React and Tailwind CSS version of the GlowNest perfume and cosmetics website.

## Step-by-step editing

1. Run `npm install` once.
2. Run `npm run dev` to start the website.
3. Open `http://127.0.0.1:3005/` in your browser.
4. Put your advertisement post images inside `assets/posts`.
5. In `src/data/products.js`, replace the sample product names and prices with your real products.
6. Adjust each page design in `src/pages/HomePage.jsx`, `src/pages/PerfumesPage.jsx`, and `src/pages/CosmeticsPage.jsx`.
7. Keep the WhatsApp number as `94766721584` for direct ordering links.

## Main project files

- Home page: `src/pages/HomePage.jsx`
- Perfumes page: `src/pages/PerfumesPage.jsx`
- Perfume detail page: `src/pages/PerfumeDetailPage.jsx`
- Cosmetics page: `src/pages/CosmeticsPage.jsx`
- Cart page: `src/pages/CartPage.jsx`
- Shared header: `src/components/Header.jsx`
- Shared footer: `src/components/Footer.jsx`
- Product cards: `src/components/ProductCard.jsx`
- Product data: `src/data/products.js`
