# 🌸 GlowNest

GlowNest is a modern full-stack e-commerce platform designed for selling perfumes, skincare, and beauty products.

## Features

- User Authentication
- Product Catalog
- Product Search & Filtering
- Shopping Cart
- Secure Checkout
- Payment Gateway Integration
- Invoice Generation
- Order Management
- Responsive Design
- Admin Dashboard

## Tech Stack

### Frontend
- React
- Vite
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL
- Sequelize ORM
